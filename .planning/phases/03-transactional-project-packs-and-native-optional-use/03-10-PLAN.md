<objective>
Prove the six representative domains with deterministic, offline, three-OS-portable fixtures.

Purpose: CAPA-08 requires representative evidence-based packs for web, API/data, infrastructure, agent/AI,
security and scientific projects without installing broad language or framework profiles globally.
CONTEXT.md D-15 chooses synthetic fixture repositories built by the tests, with near-miss negatives from
the same scaffold, precisely because that is deterministic, offline and portable to the three-OS matrix —
invocation proof is not run for all six, and one representative pack carries the invocation half through
the pass-bar canary.

RESEARCH.md Pitfall 7 found that one locked skill ships a companion file its own text never references, so
the one-file materialization rule is safe today by coincidence rather than by contract. Making it an
asserted property is what turns the next runtime bump from a silent partial materialization into a loud
one.

Output: a fixture scaffold, twelve fixtures, and a plan-time shape guard.
</objective>
