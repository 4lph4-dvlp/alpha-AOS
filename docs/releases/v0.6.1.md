# alpha-AOS v0.6.1

- Managed Cua GUI support and native capability discovery from the former release branch.
- Direct pushes and personal workstation deployment with npm run deploy:local.
- CI, tests and dependency promotion are manual operations; no automatic promotion schedule.
- Release-branch planning evidence and optional GSD prohibition verification tools retained.
- Local and remote branches consolidated, retaining prior tips in main's commit ancestry. Old dependency proposals were retired without changing stable dependency pins. An alternative uncommitted bootstrap implementation is retained as a patch and in its detached worktree.

Built on Windows. Build and CLI startup were checked for this release; automated tests and cross-platform CI were intentionally not run. The previously tested integration commit is historical evidence, not a test result for this release. GitHub release only; no npm registry publication.
