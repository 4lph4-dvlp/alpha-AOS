## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scanned manifest files → dependency readers | `package.json`, `pyproject.toml`, `requirements.txt`, `go.mod`, `Cargo.toml` are all untrusted repository bytes. |
| scanned file bytes → `fileContent` detector | Arbitrary content, possibly credential-bearing, matched against repository-owned patterns. |
| evidence envelope → downstream plan and possibly-committed artifact | Anything recorded here can end up in a file a team commits. |
