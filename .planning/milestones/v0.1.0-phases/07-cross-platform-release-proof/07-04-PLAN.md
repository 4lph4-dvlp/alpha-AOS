Implement smoke tester and preview-first release orchestrator adhering to D-15, D-16, REL-05, and REL-06:

1. Create `scripts/smoke-test.mjs`:
   - Shebang `#!/usr/bin/env node`.
   - Export `runSmokeTest(target, isRegistry = false)`:
     - Create temporary sandbox via `mkdtemp(join(tmpdir(), "alpha-aos-smoke-"))`.
     - Subdirectories: `home`, `prefix`, `state`.
     - Construct isolated environment redirecting `HOME`, `USERPROFILE`, `ALPHA_AOS_STATE_DIR`, `npm_config_prefix`.
     - Run `npm install -g <target> --prefix <prefixDir>` via `child_process.spawnSync`. If installation fails, output stderr and return exit code 1.
     - Resolve installed binary: `prefix/alpha-aos.cmd` (or `prefix/bin/alpha-aos.cmd`) on Windows; `prefix/bin/alpha-aos` on macOS/Linux.
     - Sequentially execute `alpha-aos --version`, `alpha-aos status`, and `alpha-aos doctor`. If any command returns non-zero exit code, log failure and return exit code 1.
     - Clean up sandbox recursively upon completion.
     - Output success message and return exit code 0.
   - Handle CLI flags: `--local` (or `--tarball <path>`) executes Stage 1; `--registry` (or `--registry <version>`) executes Stage 2. When `--local` is specified without an explicit `--tarball` argument, check if `alpha-aos-0.1.0.tgz` exists; if not, automatically run `npm run build && npm pack` to generate the authoritative tarball before running the smoke test. This ensures that direct invocations like `node scripts/smoke-test.mjs --local` succeed without requiring a separate manual pack command.

2. Create `scripts/release.mjs`:
   - Shebang `#!/usr/bin/env node`.
   - Implement preview-first release workflow:
     - Check Git clean status (`git status --porcelain`) and active branch (`main`). Fail if dirty unless `--allow-dirty` is explicitly provided for testing.
     - Run check (`npm run check`) and build (`npm run build`).
     - Run test suite (`npm test`).
     - Run tarball audit (`node scripts/audit-tarball.mjs --prepack`).
     - Pack tarball (`npm pack`) to produce `alpha-aos-0.1.0.tgz`.
     - Compute SHA-256 and generate `alpha-aos-0.1.0.tgz.sha256`.
     - Verify provenance (`node scripts/verify-provenance.mjs alpha-aos-0.1.0.tgz`).
     - Run Stage 1 smoke test (`node scripts/smoke-test.mjs --tarball alpha-aos-0.1.0.tgz`).
     - Check for `--publish` flag:
       - If `--publish` is absent: print dry-run summary with generated artifact hashes, confirming that all verification gates passed, and exit 0.
       - If `--publish` is present: execute `npm publish alpha-aos-0.1.0.tgz --access public`. After publication succeeds, run Stage 2 smoke test (`node scripts/smoke-test.mjs --registry alpha-aos@0.1.0`). Print final release confirmation and exit 0.
  </action>
