<objective>
Implement same-harness reviewer isolation, reviewer diversity contract policy (`differentReviewerPolicy`), and the post-review Tree Mutation Guard.

Purpose: Satisfy ROL-04 and user decisions D-09, D-10, and D-11. Prevent reviewer session pollution and covert tree modification. Provide explicit policy configuration for requiring distinct reviewer harnesses or models. Run same-harness reviewers in isolated ephemeral environments with unique session IDs and read-only tools. Detect and invalidate any review that mutates the project tree with `INVALID_MUTATING_REVIEW`.

Output: `schemas/task-contract.schema.json`, `src/core/tree-mutation-guard.ts`, updated `src/core/task-contract.ts`, updated `src/core/task-run.ts`, and test suites.
</objective>

  <action>
    1. Create `src/core/tree-mutation-guard.ts`:
       - Define `IGNORED_OS_FILES = new Set([".DS_Store", "Thumbs.db", "desktop.ini"])`.
       - Implement `captureTreeSnapshot(projectRoot: string, allowedRoots: string[]): Promise<TaskArtifactManifest>` using `collectTaskArtifact`.
       - Implement `evaluateTreeMutations(before: TaskArtifactManifest, after: TaskArtifactManifest): TreeMutationResult`:
         - If `before.digest === after.digest`, return `{ mutated: false, code: "ok", violations: [] }`.
         - Map before and after file SHA-256 hashes.
         - For files in after but not before (excluding `IGNORED_OS_FILES`): record violation `created: <path>`.
         - For files with changed hash: record violation `modified: <path>`.
         - For files in before but not after (excluding `IGNORED_OS_FILES`): record violation `deleted: <path>`.
         - If violations exist, return `{ mutated: true, code: "INVALID_MUTATING_REVIEW", violations }`.
    2. Integrate `TreeMutationGuard` into `src/core/task-run.ts`:
       - Immediately prior to invoking `reviewerPort.review`, take pre-review snapshot: `const preReviewTree = await captureTreeSnapshot(options.projectRoot, allowedRoots)`.
       - After `reviewerPort.review` completes:
         - Take post-review snapshot: `const postReviewTree = await captureTreeSnapshot(options.projectRoot, allowedRoots)`.
         - Evaluate mutations: `const mutation = evaluateTreeMutations(preReviewTree, postReviewTree)`.
         - If `mutation.mutated`:
           - Override review result with an invalid review verdict: `{ verdict: "rejected", reason: "INVALID_MUTATING_REVIEW: reviewer violated read-only invariant and modified project tree: " + mutation.violations.join(", ") }` (D-11).
    3. Create `test/task-tree-guard.test.ts`:
       - Test clean review: file tree unmodified -> `mutated: false, code: "ok"`.
       - Test rogue reviewer modifying an existing file -> `mutated: true, code: "INVALID_MUTATING_REVIEW"`, lists `modified: <file>`.
       - Test rogue reviewer creating a new file -> `mutated: true`, lists `created: <file>`.
       - Test rogue reviewer deleting a file -> `mutated: true`, lists `deleted: <file>`.
       - Test that OS metadata files (`.DS_Store`, `Thumbs.db`) do not trigger a mutation violation.
