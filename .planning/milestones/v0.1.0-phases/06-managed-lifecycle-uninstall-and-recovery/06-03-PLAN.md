2. In `src/core/transaction.ts`:
   - Export error class `RollbackDriftError extends Error` containing `diagnostics: DriftDiagnostic[]`.
   - Export `generateUnifiedDiff(target: string, expectedText: string, actualText: string, expectedHash: string, actualHash: string): string`:
     - Generates standard Unified Diff headers (`--- a/...`, `+++ b/...`, `@@ -1,... +1,... @@`).
     - Includes lines unique to expected with `-` prefix and lines unique to actual with `+` prefix.
   - Export `sweepReverseDirectories(filePath: string, allowedRoots: readonly string[]): Promise<string[]>`:
     - Resolves parent directory of `filePath`.
     - Recursively calls `rmdir` on parent directory while it is empty.
     - If `rmdir` throws `ENOTEMPTY` or `EEXIST`, immediately catches and halts climbing (non-empty user directories preserved).
     - Stops climbing when reaching any path in `allowedRoots`.
     - Returns list of successfully swept directory paths.
   - In `planManagedRollback(stateRoot: string, id: string)`:
     - Enforce LIFO head-of-chain ordering (`D-07`):
       - Query all transactions via `listManagedTransactions(stateRoot)`.
       - Filter for transactions with `status === "applied"`.
       - Find the head transaction (first item in reverse chronological order).
       - If `head !== undefined && head.id !== id`:
         throw new Error(`LIFO violation: transaction ${id} is not the most recent active transaction (head: ${head.id}). Roll back ${head.id} first.`);
   - In `rollbackFileTransaction(stateRoot: string, id: string, allowedRoots: string[])`:
     - Enforce All-or-Nothing preflight verification (`D-05`, `D-06`):
       - Iterate through all entries in `journal.files`.
       - For each file, check existence and compute SHA-256 hash.
       - Compare against `file.afterHash`:
         - If `file.afterHash === null` and file exists: drift detected.
         - If `file.afterHash !== null` and (file missing OR hash mismatch): drift detected.
       - If ANY file drifted:
         - For each drifted file, read actual text and compare against snapshot text.
         - Generate `DriftDiagnostic` with target path, expected hash, actual hash, unified diff snippet, and remediation guidance:
           `"Reconcile file manually or restore from snapshot: ~/.alpha-aos/snapshots/<id>/..."`.
         - Throw `RollbackDriftError` carrying all diagnostics.
         - ZERO disk writes are executed.
     - If all files pass preflight:
       - Restore snapshots in reverse order.
       - For newly created files (`file.existed === false`), unlink the file and call `sweepReverseDirectories(file.target, allowedRoots)`.
       - Mark journal `status: "rolled-back"` and write atomically.
