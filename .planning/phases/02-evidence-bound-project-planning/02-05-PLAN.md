## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scanned repository directory tree → collector | Directory names, symlink targets, `.gitignore` contents and workspace declarations are all attacker-controlled if the repository is. |
| workspace declaration → member paths | A declaration names paths that the collector will then read. |
| filesystem identity → traversal control | Device/inode identity is what makes a cycle terminable. |
