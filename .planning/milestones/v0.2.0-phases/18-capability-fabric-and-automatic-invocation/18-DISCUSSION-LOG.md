## 기능 선택 중복

| 질문 | 제시한 선택지 | 사용자 선택 |
|---|---|---|
| 버전별 API 문서와 최신 외부 사례가 모두 필요할 때 | Context7과 Exa·Firecrawl 각각 호출; 주된 경로 먼저 호출; 다른 규칙 | 두 경로 각각 호출 |
| 프로젝트 전용 스킬과 전역 스킬이 같은 필요를 충족할 때 | 프로젝트 전용 우선; 조건에 맞는 스킬 모두 호출; 다른 우선순위 | 프로젝트 전용 우선 |
| 작업 설명만으로 적용 여부가 불분명할 때 | 계획·파일·GSD 단계 근거 확인; 가능성만으로 호출; 바로 사용자 입력 요청 | 작업 근거 확인 |
| 같은 자료가 계획·검증 단계에 모두 필요할 때 | 단계마다 재호출; 유효한 이전 결과·영수증 연결해 재사용; 다른 규칙 | 유효한 결과 재사용 |

**Notes:** 서로 다른 근거를 주는 기능은 각각 사용한다. 중복 기능을 생략하면 이유를 기록한다. 재사용은 원래 호출의 영수증에 연결하며 새 호출로 기록하지 않는다. 추가 논의 없이 다음으로 진행했다.

## 필수 기능 대체 경로

| 질문 | 제시한 선택지 | 사용자 선택 |
|---|---|---|
| 필수 기능 실패 시 복구·대체 순서 | 현재 경로 복구 우선; 검증된 대체 경로 우선; 상황별 기준 | 현재 경로 복구 우선 |
| 대체 경로가 계약의 역할·하네스를 바꿀 때 | 새 승인 요청; 사전 승인 후보 안에서 자동 전환; 다른 경계 | 새 승인 요청 |
| 동등한 대체 경로의 기준 | 필요한 결과와 출처·버전·실제 호출 증거 동등; 미리 등록된 관계만; 다른 기준 | 결과와 증거 동등 |
| 복구·대체 실패 뒤 사용자 조치가 남을 때 | `needs-input` 대기, 경로 없으면 `blocked`; 즉시 `blocked`; 다른 규칙 | 사용자 조치 대기 |

**Notes:** 복구는 승인된 권한 안에서만 시도한다. 사용자 조치가 가능한 경우 조치와 중단 원인을 제시한다. 추가 논의 없이 다음으로 진행했다.

## 호출 증거와 결과 표시

| 질문 | 제시한 선택지 | 사용자 선택 |
|---|---|---|
| 스킬이 MCP를 안내할 때 필요한 증거 | 스킬 활성화와 MCP 호출·결과 각각 증명; MCP 결과로 함께 증명; 다른 기준 | 각각 증명하고 연결 |
| 실제 호출이 오류로 끝날 때 | 호출됨·실패 분리 표시; 미검증으로만 표시; 다른 방식 | 호출됨·실패 분리 표시 |
| `task plan/status` 기본 화면 범위 | 선택·실패·차단 중심 요약과 별도 전체 보기; 기본 화면에 전체 목록; 다른 구성 | 작업 중심 요약 |
| 버전·팩 원본 변경으로 증거가 무효가 될 때 | 변경 원인·영수증·다음 조치 표시; 무효 상태만 표시; 다른 기준 | 원인과 조치 표시 |

**Notes:** 실패한 호출 영수증은 남기지만 성공한 기능 사용으로 승격하지 않는다. 전체 기능 목록은 상세 보기와 JSON에서 확인한다. 사용자는 이 영역의 추가 논의 대신 문서 작성을 선택했다.
