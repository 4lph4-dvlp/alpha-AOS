`export class BoundedStdioTransport implements Transport`를 추가한다. `Transport`는 `@modelcontextprotocol/sdk/shared/transport.js`에서 type import한다. 생성자는 `ProtocolProcessSpec`를 받아 보관만 한다. `start(): Promise<void>`는 `openProtocolProcess(this.spec)`를 호출해 session을 열고 `session.onMessage(...)`를 등록한다. 등록된 listener는 받은 object를 `@modelcontextprotocol/sdk/types.js`의 `JSONRPCMessageSchema`로 `parse`한 뒤에만 `this.onmessage`에 넘긴다 — alpha-AOS는 byte bound와 process boundary만 소유하고 MCP message semantics는 SDK schema에 위임한다. parse가 실패하면 `this.onerror`에 raw byte 없이 coded 사유만 담은 `Error`를 넘기고 그 message는 버린다. `send(message)`는 `this.session.send(message)`를 호출한다(session이 `JSON.stringify(message) + "\n"`으로 framing하며 이는 SDK `serializeMessage`와 동일하다). `close()`는 `await this.session.close()` 후 `this.onclose?.()`를 부르고, 이미 닫혔으면 아무 것도 하지 않는다. session이 자체 사유(cap, deadline, child exit)로 settle하면 `closed`가 resolve될 때 `this.onclose?.()`를 부른다. `start()`가 아직 호출되지 않았거나 session이 열리지 못한 상태에서 `send`가 오면 `Error`를 던진다 — SDK transport로 되돌아가는 fallback 분기를 만들지 않는다.
