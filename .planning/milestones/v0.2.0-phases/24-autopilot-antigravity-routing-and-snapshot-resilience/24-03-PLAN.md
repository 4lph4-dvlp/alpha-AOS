# 24-03: Snapshot `.planning` Read-Only Mirroring & `verifyGsdEvidence` Retry Resilience

## Goal

Eliminate false reviewer/measurement failures caused by missing `.planning` files in isolated snapshots (`BUG-03`) and eliminate base-commit lock-in when re-running a contract revision that reuses an existing `.planning/quick/<id>` directory (`BUG-04`).

## Context

- `24-CONTEXT.md` Decision D-04: Mirror regular files from `<projectRoot>/.planning` into `<snapshot>/.planning` (read-only) inside `materializeTaskSnapshot` after artifact digest verification, keeping `.planning` excluded from `collectTaskArtifact` digests.
- `24-CONTEXT.md` Decision D-05: Extend `verifyGsdEvidence` in `src/core/task-gsd.ts` and `startTask` in `src/core/task-run.ts` so contract retries (`revision > 1`, prior runs, or post-`baseCommit` activity) can verify a claimed existing `.planning/quick/<id>` directory and its `docs(quick-<id>)` commit across git history.

## Tasks

1. **Mirror Read-Only `.planning` Metadata in `materializeTaskSnapshot` (`src/core/task-check.ts`)**:
   - After copying `manifest.files` and verifying `collectTaskArtifact` digest parity in `materializeTaskSnapshot`, recursively copy regular non-symlink files under `<projectRoot>/.planning` into `<destination>/.planning` with read-only permissions (`0o444`).
   - Confirm that `collectTaskArtifact` on `<destination>` still produces the exact same `manifest.digest` and `manifest.files`.
2. **Make `verifyGsdEvidence` Retry-Resilient (`src/core/task-gsd.ts`, `src/core/task-run.ts`)**:
   - Add `allowExistingClaimedQuick?: boolean` to `verifyGsdEvidence`.
   - When `fresh` has no matching new quick directory, allow a claimed directory in `current` if `allowExistingClaimedQuick` is true or if commits/changes exist after `baseCommit`, and allow `docs(quick-<id>)` commit lookup to fall back to `HEAD` history when the directory was created in a prior attempt.
   - Pass `allowExistingClaimedQuick: contract.revision > 1 || priorRuns.length > 0` from `startTask` in `src/core/task-run.ts`.
3. **Add Comprehensive Regression Test Suite (`test/task-autopilot-bugfixes.test.ts`)**:
   - Write end-to-end and unit tests covering BUG-01, BUG-02, BUG-03, BUG-04, and BUG-05.
