<objective>
Close gap `G-07-1` (07-VERIFICATION.md): D-18 (03-CONTEXT.md, 2026-09-22) reinstated Claude Code into the active v0.1.0 harness scope on equal footing with Codex, Antigravity, Pi, and Hermes, but `src/core/support-matrix.ts` still hardcodes `harnessId === "claude"` to a fixed compatibility-only tier and types `activeSurfaces` to exclude claude entirely — a structural exclusion that makes Claude incapable of ever reaching the top tier no matter what evidence exists. This plan removes that hardcode and widens the type so Claude is judged by the exact same evidence rule as every other harness: no free pass to the top tier, and no structural ceiling below it.

Purpose: Make the v0.1.0 support matrix honest about D-18. Claude's own real invocation-receipt evidence is a separate matter (see the explicit deferral in Task 2) — this plan only removes the code-level impossibility of Claude ever being judged on that evidence.
