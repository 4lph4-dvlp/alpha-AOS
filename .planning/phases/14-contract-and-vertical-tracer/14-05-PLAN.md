## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| controller -> project working tree | The agent may write anywhere its sandbox allows, including outside approved roots |
| project `.planning/` -> verifier | GSD artifacts are read as evidence; they could be forged by the controller |
| gsd-tools stdout -> readiness | Output of an installed third-party script |
| alpha-AOS -> project-pack state | A dependency change could lead to an unapproved pack sync |
