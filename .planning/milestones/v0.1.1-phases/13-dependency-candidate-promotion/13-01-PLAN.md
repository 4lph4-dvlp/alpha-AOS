## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| NPM Registry → scripts/promote-candidate.mjs | Metadata fetched over HTTPS is parsed as JSON; `dist.integrity` is validated against SHA-512 SRI format before adoption. |
| Child Process → mcp-fixture.ts | Child process outputs (`npm pack --json`, stdio JSON-RPC) are constrained by byte limits (`maxOutputBytes`, `excerptBytes`) and timeouts to prevent hanging or memory exhaustion. |
| User/Maintainer CLI → scripts/promote-candidate.mjs | Component names are allowlisted against declared lock component keys (`gsd`, `ecc`, `context7`, `firecrawl`, `pi`); arbitrary input cannot inject new schema keys. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-01 | Tampering | scripts/promote-candidate.mjs | high | mitigate | Subresource Integrity (SRI) SHA-512 hashes are verified against npm registry metadata and validated by `schemas/lock.schema.json`. |
| T-13-02 | Denial of Service | src/core/mcp-fixture.ts | medium | mitigate | Pass explicit `excerptBytes: 256 * 1024` and `maxOutputBytes: 256 * 1024` to prevent buffer truncation and unhandled JSON parse exceptions. |
| T-13-03 | Elevation of Privilege | src/core/mcp-fixture.ts | high | mitigate | Direct launcher resolution via `resolveDirectLaunch` on Windows ensures shell-free argument vector execution without invoking cmd.exe or shell interpolation. |
| T-13-04 | Tampering | scripts/pin-pack-skills.mjs | high | mitigate | Pinned skill hashes are computed using SHA-256 over raw extracted skill files from verified tarballs, ensuring deterministic reproducibility. |
| T-13-05 | Information Disclosure | src/core/mcp-fixture.ts | medium | mitigate | Protocol sessions use synthetic redaction nonces and pass-through allowlists, preventing real user credentials from being leaked to fixture children. |
