# 24-01: Antigravity Model Tier Routing & Subagent Guardrails

## Goal

Ensure Antigravity CLI (`agy`) invocations in autopilot roles explicitly receive `--model <model-id>` from contract `agentPolicy` or `.planning/config.json`, and prevent silent model downgrades when invoking subagents with `typeName: "self"` (`BUG-01`, `BUG-05`).

## Context

- `24-CONTEXT.md` Decision D-01: Parameterize `agentPolicy` (`controllerModel`, `executorModel`, `reviewerModel`) and `.planning/config.json` fallback in `src/adapters/task-antigravity.ts`.
- `24-CONTEXT.md` Decision D-02: Fail closed with `INCOMPATIBLE_SUBAGENT_MODEL` when `typeName: "self"` is combined with a cross-tier `Model` override, and instruct controllers in `buildGsdControllerPrompt` to use dedicated role subagents or CLI `--model` flags.

## Tasks

1. **Extend Contract Schema & Digesting (`schemas/task-contract.schema.json`, `src/core/task-contract.ts`)**:
   - Add optional `controllerModel`, `executorModel`, and `reviewerModel` properties to `agentPolicy` in `schemas/task-contract.schema.json` and `TaskAgentPolicy` in `src/core/task-contract.ts`.
   - Include defined model fields in `digestableTaskContract` and `changedContractFields` while keeping digests unchanged when model fields are omitted.
2. **Update Antigravity Task Adapter (`src/adapters/task-antigravity.ts`)**:
   - Add `model?: string` to `antigravityControllerArgs`, `antigravityExecutorArgs`, and `antigravityReviewerArgs`, injecting `["--model", model]` when present.
   - Implement `resolveAntigravityRoleModel` to resolve model IDs from `AntigravityAdapterOptions`, `contract.agentPolicy`, or `<projectRoot>/.planning/config.json` (`model_profile_overrides` and `cross_ai_command`).
   - Implement `validateAntigravitySubagentDispatch` throwing/returning `INCOMPATIBLE_SUBAGENT_MODEL` when `typeName === "self"` is paired with a conflicting explicit `Model` tier.
3. **Update Controller Prompt Guardrails (`src/core/task-gsd.ts`)**:
   - Add subagent model routing rule to `buildGsdControllerPrompt` forbidding `typeName: "self"` with non-`inherit` model overrides.

## Verification

- `npm run check` passes.
- Unit tests verify `--model` injection in `antigravityControllerArgs`, `antigravityExecutorArgs`, `antigravityReviewerArgs`, `.planning/config.json` resolution, contract digest stability, and `INCOMPATIBLE_SUBAGENT_MODEL` refusal.
