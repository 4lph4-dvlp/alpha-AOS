<objective>
Close the two remaining review findings that change no plan-value shape: WR-09's root-blind caches and
W-3's homeless drift check.

This plan is the sibling of 02-15 and exists because the two are independent. 02-15 owns the two findings
that widen `ProjectCapabilityPlan` and therefore the committed approval artifact; nothing here touches
`src/types.ts`, `src/format.ts` or `schemas/`, and nothing here changes a digest, a schema or a published
contract. Splitting them keeps each plan inside the per-plan context budget and keeps the shape-change
review — which is the risky half — undiluted by mechanical work.

WR-09: the pack catalog and the fact vocabulary are loaded from the caller-supplied `options.packageRoot`,
but the declared pack id set and the manifest schema are loaded from a root rediscovered inside
`src/core/project.ts`, and both are memoized in module state keyed on nothing. The unknown-pack-override
check can therefore be validated against a DIFFERENT catalog than the one that evaluates the packs, and
the first caller in a process decides the catalog for every later caller in that process.

W-3: `node scripts/pin-pack-skills.mjs check` is substantive, it works, and it has no caller anywhere in
`.github/` or `package.json`, so the catalog and the lock can drift silently.

Purpose: DETC-02 promises that a user can see the evidence — including manifest evidence — that selected
each pack, and a refusal decided by the wrong catalog is not that. D-05 makes `catalog/packs/*.yaml` the
single authority for pack predicates and D-06 makes a manifest override itself auditable evidence; both
are void if the override is judged against a catalog other than the one that evaluated the packs. DETC-04
promises exact source version and hash, and D-08 requires every pack skill's source hash to be pre-pinned
in `catalog/stack.lock.json` — a silently drifting lock quietly stops delivering both.

Output: one package root deciding one catalog through root-keyed, bounded caches, and a drift check with
a named home on a stated cadence.
</objective>
