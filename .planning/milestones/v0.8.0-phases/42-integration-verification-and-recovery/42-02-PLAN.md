## Trust Boundaries

| Boundary | Description |
|---|---|
| verifier result → durable lifecycle | 외부 process/proxy 결과가 state-root record로 직렬화된다. |
| lifecycle writer → transaction store | operation ID, sequence와 path가 owned-file mutation boundary를 지난다. |
| new lifecycle reader → old acceptance reader | 새 상태가 과거 accepted 의미와 함께 조회되지만 서로를 재해석해서는 안 된다. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-42-04 | Tampering | lifecycle schema/reader | high | mitigate | closed versioned schema와 old-record byte-preservation test로 기존 accepted 의미 재해석을 차단한다. |
| T-42-05 | Repudiation | append-only events | high | mitigate | monotonic sequence, canonical digest, journal-backed transaction 및 retry byte comparison으로 overwrite를 탐지한다. |
| T-42-06 | Denial of Service | lifecycle writer ownership | high | mitigate | one-writer session과 operation-scoped lock으로 concurrent/out-of-order append를 mutation 전에 거부하는 race test를 둔다. |
| T-42-SC | Tampering | npm/pip/cargo installs | high | mitigate | 새 package install 없이 기존 schema validator/transaction 경계를 재사용하며 install task가 생기면 legitimacy gate를 요구한다. |
</threat_model>
