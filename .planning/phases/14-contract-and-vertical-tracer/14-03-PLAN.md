<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reviewer report -> reducer | LLM-authored findings, reproductions and suggestions are untrusted data |
| decision log -> run record | Controller-written JSON lines in the project tree are untrusted data |
| agent-written program -> measurement and confirmation | Executed under the user's account |
| project tree -> snapshot | The project may change while measurement and review run |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-16 | Tampering | stale review substitution | high | mitigate | assessTaskReview stale on requestId, contractDigest, artifactDigest or session mismatch; never accepted (tests) |
| T-14-17 | Tampering | artifact change during review | high | mitigate | Re-collect project and snapshot digests after review; stale-artifact refusal |
| T-14-18 | Elevation of Privilege | reviewer-supplied reproduction | high | mitigate | confirmReviewerReproduction runs only process.execPath with the contract entry; reviewer text is written to a scratch file as data and never executed as a command |
| T-14-19 | Elevation of Privilege | measurement substitute | high | mitigate | Substitute type carries only an entry path; path normalized and confined to allowed roots; expectations stay the contract's |
| T-14-20 | Repudiation | unconfirmed reviewer failure | medium | mitigate | Unconfirmed fail is unknown with a next action, preserving both records rather than silently accepting or rejecting |
| T-14-21 | Denial of Service | decision log and artifact size | medium | mitigate | 256 KiB and 200-line log bound; 2000-file and 16 MiB artifact bound; 64 KiB measurement output cap with process-tree kill beyond eight times the cap |
| T-14-22 | Information Disclosure | decision log and report text | medium | mitigate | rejectRawCredentials on each decision line and on the report; details bounded to 300 characters from parsed or redacted output |
