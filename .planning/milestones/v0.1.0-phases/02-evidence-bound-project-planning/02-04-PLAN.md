<objective>
Pre-pin every pack skill's source hash in `catalog/stack.lock.json` so that `alpha-aos project plan`
can name each selected pack's exact source version and hash while touching no network and no package
manager (D-08).

Purpose: `src/core/ecc-skills.ts:65` throws when `sourceSha256` lacks a skill. Without pinning, the
first pack whose skill is unpinned makes planning fail at the moment it is needed — and resolving at
plan time would put an npm invocation back on a preview path, which is exactly what plan 01-21 removed
because it wrote into the user's home during a preview.

Output: a maintainer-only pinning script driven by the integrity-checked fixture, 19 new
`sourceSha256` entries, a coverage test that fails the moment a pack names an unpinned skill, and an
anti-regression test proving the global sync list did not grow.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → `scripts/pin-pack-skills.mjs` | The maintainer-side acquisition of `ecc-universal@2.2.0`; the only place in this plan where a package manager runs. |
| `catalog/stack.lock.json` → `project plan` | The lock is the offline authority for source version and hash; nothing downstream re-resolves it. |
| global `node_modules` install → the lock | An attractive but untrusted shortcut for producing hashes. |
