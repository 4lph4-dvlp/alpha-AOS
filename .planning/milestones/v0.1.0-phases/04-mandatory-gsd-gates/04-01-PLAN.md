In `src/core/gate.ts`:
- Implement `resolvePhaseGitDiff(projectRoot: string, options?: { explicitBase?: string }): Promise<GitDiffRange>`.
  1. Resolve `git` executable path via `resolveCommand("git")`. If missing, throw informative error.
  2. Run `git rev-parse HEAD` via `runProcess` (shell-free, bounded output) to obtain `headCommit`.
  3. Determine `baseCommit`:
     - If `options?.explicitBase` provided, verify it via `git rev-parse <explicitBase>`.
     - Otherwise, attempt `git merge-base origin/main HEAD`, `git merge-base main HEAD`, `git merge-base origin/master HEAD`, `git merge-base master HEAD`.
     - Fallback: read `state_head` from `.planning/STATE.md` if available.
     - Final fallback: root commit (`git rev-list --max-parents=0 HEAD`).
  4. Query cumulative modified files between `baseCommit` and working tree via `git diff --name-only <baseCommit>`.
     Normalize path separators to POSIX forward slashes (`/`).
  5. Query untracked files via `git status --porcelain`. Extract files with `?? ` prefix.
  6. Return `GitDiffRange` with sorted, deduplicated `modifiedFiles` and `untrackedFiles`.
  </action>

    - Cumulative diff covers from `baseCommit` through intermediate commits and working-tree modifications.
    - Untracked files are captured via `git status --porcelain`.
    - All file paths are normalized to POSIX forward slashes.
