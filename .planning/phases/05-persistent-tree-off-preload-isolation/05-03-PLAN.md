2. In `src/core/tree-policy.ts`:
   - Implement `findEnclosingGitRoot(targetPath: string): Promise<string | null>`:
     - Canonicalize `targetPath` using `canonicalizeTreePath`.
     - Walk upwards ancestor directories checking for `.git`.
     - Check both `stat.isDirectory()` (standard repo) and `stat.isFile()` (git worktree or submodule pointer).
     - Stop at filesystem root. Return canonical root path or null if not in a git repository.
   - Implement `promptFirstUseClassification(gitRoot: string, options?: { stdin?: NodeJS.ReadableStream; stderr?: NodeJS.WritableStream }): Promise<FirstUseChoice>`:
     - Write prompt header to `stderr` explaining newly encountered repository root:
       `alpha-AOS: Newly encountered Git repository root:`
       `  ${gitRoot}`
       `Select policy for this repository:`
       `  [1] Managed (적용)       - Enable alpha-AOS project management and capabilities`
       `  [2] Off (격리)          - Isolate from global customizations, vanilla harness with local resources`
       `  [3] 나중에 결정 (Skip)   - Ask next time, pass through this invocation only`
     - Read line from `stdin`. If user enters `"1"` or `"managed"`, return `"managed"`.
     - If user enters `"2"` or `"off"`, return `"off"`.
     - If user enters `"3"`, `""`, or `"skip"`, return `"ask-next-time"`.
     - Loop until a valid choice is provided.
   - Implement `classifyGitRootOrFallback(gitRoot: string, options?: { isTTY?: boolean; defaultModeEnv?: string; stdin?: NodeJS.ReadableStream; stderr?: NodeJS.WritableStream; stateRoot?: string }): Promise<ClassificationResult>`:
     - Check `isTTY = options?.isTTY ?? (Boolean(process.stdin.isTTY) && !process.env.CI)`.
     - If `!isTTY`:
       - Check `options?.defaultModeEnv ?? process.env.ALPHA_AOS_DEFAULT_MODE`.
       - If override equals `"managed"`, return `{ mode: "managed", persisted: false, gitRoot, reason: "default-mode-override" }`.
       - Default to Fail-Safe Off: return `{ mode: "off", persisted: false, gitRoot, reason: "ci-fallback" }`.
     - If `isTTY`:
       - Call `promptFirstUseClassification(gitRoot, options)`.
       - If `"managed"`: persist via `setTreePolicy(gitRoot, "managed", { stateRoot: options?.stateRoot })`, return `{ mode: "managed", persisted: true, gitRoot, reason: "interactive" }`.
       - If `"off"`: persist via `setTreePolicy(gitRoot, "off", { stateRoot: options?.stateRoot })`, return `{ mode: "off", persisted: true, gitRoot, reason: "interactive" }`.
       - If `"ask-next-time"`: return `{ mode: "passthrough", persisted: false, gitRoot, reason: "interactive" }`.
   - Implement clean restart handling for late discovery (OPTO-04):
     - If an active hook or harness extension discovers an unclassified or newly off tree after boot, serialize state to `trees.json` and invoke a clean subprocess restart with the target binary rather than continuing with dirty memory.

3. In `src/shim-dispatch.ts`:
   - Before launching upstream binary:
     - Check if `policy.effectiveMode === "unclassified"`.
     - Call `findEnclosingGitRoot(process.cwd())`.
     - If git root found and not registered:
       - Call `classifyGitRootOrFallback(gitRoot)`.
       - If result mode is `"off"`, proceed with off isolation pipeline; if `"managed"` or `"passthrough"`, proceed with managed delegation.
  </action>
