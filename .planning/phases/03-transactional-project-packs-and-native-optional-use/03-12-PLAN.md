<objective>
Prove the cross-harness handoff and, in the same run, prove it did not become project policy.

Purpose: CAPA-03 requires an explicit cross-harness handoff through Unified Memory without Memory Vault
content modifying `.planning/` or becoming authoritative project policy. CONTEXT.md D-16 makes that one
run rather than two: harness A writes a handoff, harness B reads it and works from that context, and
`.planning/` is verified byte-for-byte unchanged across the round trip — the positive and the negative in
one evidence unit. RESEARCH.md Pattern 5 found the write primitive is first-class in the memory runtime's
own CLI, that recall is filterable by target harness, and that every command returns a closed versioned
JSON envelope — so every step except "harness B is asked" is deterministic and offline.

PROJECT.md's key decision and CONTEXT.md D-02 both bound the scope: alpha-AOS does not police the memory
tool's filesystem access, because doing so would require being an invocation proxy for every tool call.
What alpha-AOS proves is the state of `.planning/` before and after.

Output: a bounded memory adapter, the planning-tree immutability check, and one recorded evidence unit.
</objective>

Write the six behaviours as failing tests first, then implement.

`hashPlanningTree(root)` returns a `PlanningTreeDigest` carrying an aggregate digest, a sorted per-file
record of relative POSIX path to content hash, and a list of paths that could not be read. Sort by the
relative path in code-point order and normalise separators to POSIX so two hosts hashing the same content
agree — the same discipline that made the plan digest host-independent in Phase 2.

An unreadable path marks the digest INCOMPLETE and is listed with its errno. Do not compute an aggregate
over a partial set and present it as an answer: a digest that silently skipped a file would let a change
inside that file pass the immutability check, which is the one thing this function exists to prevent.
That mirrors the reasoning already recorded for unreadable evidence files one layer down.

The comparison surface returns WHICH paths differ, not merely that the digests differ. A report saying the
planning tree changed without naming the file is not actionable, and naming it is what turns the check
from an assertion into evidence.

The function reads only. Test 6 asserts that directly, because a check that modified the thing it measures
would be worse than no check.
