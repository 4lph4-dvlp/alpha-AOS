<objective>
Fix CI-01 at its root cause and make the defect class unrepeatable.

`destinationFor resolves destinations across all five harnesses` (test/owned-skills.test.ts:52) builds its fixture roots from Windows drive-letter string literals. On POSIX a drive-letter string is relative, so `destinationFor` (src/core/owned-skills.ts:54, `join(resolve(customHome), ...)`) prefixes the cwd and the assertion fails on ubuntu-latest and macos-latest (CI run 35762417138). The same defect sits in `global ECC roots preserve native roots and share Agent Skills between Codex and Pi` (test/ecc-skills.test.ts:74-81), green on POSIX today only by accident.

Purpose: The POSIX legs go green because the fixtures use host path APIs (D-11), and a source-scanning guard fails the suite on every OS the next time any test asserts against a platform-specific absolute path literal (D-09, D-10). The product is correct; this is a test-side fix only.

Output: host-native fixture roots in two test files, a pure AST scanner under test/helpers, and a guard test that self-tests the scanner and scans the real tree.
</objective>

New contract this plan creates (test/helpers/path-literal-scan.ts):
- `export const ABSOLUTE_PATH_LITERAL: RegExp` — anchored at the start of the literal text: a drive letter followed by a slash or backslash, or a leading double backslash (UNC), or a leading slash followed by one of Users, home, root, tmp, var, private, opt, usr, etc, mnt, Volumes, bin and then either a slash or end of text. Unicode flag.
- `export const HOST_PATH_FUNCTIONS: ReadonlySet of string` = join, resolve, normalize, relative, dirname, basename.
- `export const PATH_LITERAL_MARKER: RegExp` — a line comment `// path-literal-ok:` followed by optional whitespace and a reason whose first character is non-space and whose length is at least four characters.
- `export interface PathLiteralViolation { readonly file: string; readonly line: number; readonly column: number; readonly literal: string; readonly via: string }` — line and column are 1-based; via is `direct host-path argument` or `binding NAME`.
- `export function scanPathLiterals(fileName: string, text: string): PathLiteralViolation[]` — pure, no fs.
