## Trust Boundaries

| Boundary | Description |
|---|---|
| lifecycle failure → native recovery command | durable operation data가 external installer mutation으로 변환된다. |
| retained/reacquired artifact → installer | prior artifact provenance/integrity가 privileged native install input이 된다. |
| native recovery → reconciliation evidence | process/file result가 actual active identity와 invocation claim으로 승격될 수 있다. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-42-10 | Tampering | recovery scope | high | mitigate | original reviewed digest/scope/path proofs를 recovery 직전 재검증하고 out-of-scope mutation zero-call test를 둔다. |
| T-42-11 | Elevation of Privilege | native command dispatch | high | mitigate | absolute executable/no-shell/env allowlist `runProcess` specs와 malicious arg/path fixtures로 injection을 차단한다. |
| T-42-12 | Information Disclosure | diagnosis/residual output | high | mitigate | secret sentinel을 native stdout/config에 심고 bounded redaction + digest-only persistence를 검증한다. |
| T-42-13 | Spoofing | recovered actual identity | high | mitigate | process/file result와 별개로 actual path/version/invocation observation을 요구하고 unknown observation은 `recovery-required`가 되는 test를 둔다. |
| T-42-SC | Tampering | npm/pip/cargo installs | high | mitigate | 새 dependency install은 없고 product-under-test의 exact official native recovery는 기존 source/integrity policy를 재사용한다; dependency 추가는 legitimacy gate 대상이다. |
