Output: hardened `src/core/task-contract.ts` and `test/task-contract.test.ts`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| contract file -> loader | User- or agent-drafted JSON becomes authority once approved |
| filesystem -> project root | A directory may be swapped for a link between approval and start |
| environment -> contract text | Credential values could be pasted into a contract and then into prompts and receipts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-09 | Elevation of Privilege | approval replay after edit | high | mitigate | Canonical digest recomputed at start; drift throws contract-drift listing changed fields (tests in Task 1) |
| T-14-10 | Tampering | revision reuse | medium | mitigate | revision-reused refusal when one revision number carries two digests |
| T-14-11 | Tampering | project root swap | high | mitigate | canonicalizeWithMissingTail recorded at approval and rechecked at start (root-changed) |
| T-14-12 | Elevation of Privilege | allowedRoots escape | high | mitigate | Absolute, parent-segment, .git, .planning and .alpha-aos roots refused before digesting |
| T-14-13 | Information Disclosure | contract text | high | mitigate | secret-in-contract refusal on credential-named environment values plus 14-01's rejectRawCredentials pattern check; messages name paths and variable names only |
| T-14-14 | Elevation of Privilege | controller role | medium | mitigate | assertControllerRole keeps the hermes worker-only policy until role proof |
| T-14-15 | Spoofing | Unicode look-alike paths | low | accept | NFC normalization makes equivalent spellings digest identically; visually confusable but distinct code points remain distinct digests, which is the safe direction |
