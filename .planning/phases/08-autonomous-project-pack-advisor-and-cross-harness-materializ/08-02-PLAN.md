1. Create `skills/alpha-aos-pack-advisor/SKILL.md`:
   - YAML frontmatter:
     ```markdown
     ---
     name: alpha-aos-pack-advisor
     description: "Autonomous advisor and materializer for alpha-AOS project capability packs. Inspects workspaces, explains matched packs with evidence, and applies approved plan digests without manual CLI intervention."
     ---
     ```
   - Content instructions:
     - Inspection: Execute `alpha-aos project plan . --json` and `alpha-aos project status . --json`.
     - Comparison: Compare `plan.selected` against `status.reconciliation.packs`. Identify unmaterialized packs.
     - Up-to-date path: If none, notify user that project capability packs are current.
     - Recommendation: If unmaterialized packs exist, present the pack ID, matched reasons/evidence, and ask user for confirmation to install.
     - Execution: Once confirmed, extract `plan.planDigest` (exact 64-char SHA-256) and execute:
       - `alpha-aos project approve . --plan-digest <digest> --apply`
       - `alpha-aos project sync . --apply`
     - Verification: Re-run `alpha-aos project status . --json` to verify deployment is `CURRENT`.
     - Safe Guidance: Tell the user that restarting their agent or reloading tools will activate the new MCP tools and skills.
     - Invariants: Never invent or truncate plan digests. Fail closed on error.
2. In `catalog/stack.yaml`:
   - Add `alpha-aos-pack-advisor` under `components.ownedSkills`:
     ```yaml
     - id: alpha-aos-pack-advisor
       source: skills/alpha-aos-pack-advisor/SKILL.md
       targets: [claude, codex, antigravity, pi, hermes]
       invocation: automatic
     ```
3. Calculate exact SHA-256 hashes of `skills/alpha-aos-pack-advisor/SKILL.md` source and its rendered output for each harness target using `renderOwnedSkill`.
4. In `catalog/stack.lock.json`:
   - Register `alpha-aos-pack-advisor` under `components.ownedSkills` with `sourceSha256` and `targetSha256` for `claude`, `codex`, `antigravity`, `pi`, `hermes`.
5. In `test/catalog.test.ts`:
