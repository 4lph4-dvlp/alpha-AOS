# CLI-Anything integration

## Goal

Make CLI-Anything discoverable to all five alpha-AOS harnesses, while keeping application-specific CLIs selected by task and preserving GSD lifecycle and stable-lock boundaries.

## Work

1. Add a repository-owned, integrity-locked CLI-Anything skill that explains CLI-Hub discovery and use, prerequisites, and the on-demand generator path.
2. Add it to the existing five-harness owned-skill installation and capability inventory paths.
3. Document how to provision CLI-Hub and when a task may install a specific application CLI.
4. Verify catalog/lock consistency, skill rendering and inventory, targeted tests, then the full suite.

## Boundary

CLI-Hub's mutable registry and its independently published application packages are not promoted into alpha-AOS's stable lock by this task. The new skill must not present arbitrary registry entries as verified alpha-AOS dependencies.
