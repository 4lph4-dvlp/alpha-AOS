## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| alpha-AOS -> codex/claude child | Credentials must reach the native CLI by name only; prompts carry no secrets |
| codex/claude stdout -> adapters | JSONL events, final messages and reports are untrusted, possibly truncated data |
| reviewer session -> project | The reviewer must not modify the artifact or run commands |
| PATH resolution -> executable | A shim or look-alike command could be launched instead of the real CLI |
