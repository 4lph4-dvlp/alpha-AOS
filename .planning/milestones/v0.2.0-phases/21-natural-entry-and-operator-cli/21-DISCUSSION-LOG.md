## 자연어 진입

### 일반 작업 요청에서 autopilot 제안 시점

| Option | Description | Selected |
|--------|-------------|----------|
| 작업을 이해한 뒤 제안 | 목표와 범위를 짧게 파악한 후 두 경로를 제시 | ✓ |
| 첫 응답에서 바로 제안 | 작업 내용을 파악하기 전에 두 경로를 먼저 제시 | |
| 요청이 있을 때만 제안 | autopilot 언급이 없으면 일반 GSD만 진행 | |

**User's choice:** 작업을 이해한 뒤 제안.

### 일반 GSD 선택 후 진행

| Option | Description | Selected |
|--------|-------------|----------|
| 대화에서 바로 이어가기 | 같은 대화에서 적절한 GSD 흐름으로 연결 | ✓ |
| GSD 명령 안내하기 | 명령을 보여주고 사용자 입력을 기다림 | |
| 선택 화면에서 끝내기 | 경로 선택만 확인하고 이후 진행은 사용자에게 맡김 | |

**User's choice:** 대화에서 바로 이어가기.

### autopilot 선택 시 정보가 부족한 경우

| Option | Description | Selected |
|--------|-------------|----------|
| 필요한 사항만 물어보기 | 목표·완료 기준·허용 작업의 빈 부분만 확인 | ✓ |
| 초안을 먼저 보여주기 | 추정 내용을 표시하고 사용자가 미리보기에서 수정 | |
| GSD 논의부터 진행하기 | 관련 단계의 GSD 논의 후 계약 작성 | |

**User's choice:** 필요한 사항만 물어보기.

### 명시적 autopilot 요청 처리

| Option | Description | Selected |
|--------|-------------|----------|
| 선택 질문 없이 계약 미리보기로 | 경로 선택은 인정하되 계약 승인 전 실행 금지 | ✓ |
| 두 경로를 다시 제시 | 명시적 요청에도 경로를 재선택 | |
| 요청을 재확인한 뒤 미리보기로 | 별도 확인 후 계약 작성 | |

**User's choice:** 선택 질문 없이 계약 미리보기로.

## 계약 검토

### 미리보기 첫 화면의 정보 순서

| Option | Description | Selected |
|--------|-------------|----------|
| 목표·완료 기준·권한부터 | 승인 내용을 먼저, 역할·도구·한도를 뒤에 표시 | ✓ |
| 실행 방식부터 | 에이전트·도구·한도를 먼저 표시 | |
| 전체 항목을 같은 비중으로 | 요약 없이 계약을 순서대로 표시 | |

**User's choice:** 목표·완료 기준·권한부터.

### 계약 수정 후 재검토

| Option | Description | Selected |
|--------|-------------|----------|
| 전체 계약과 변경점 함께 표시 | 새 계약 전체와 이전 미리보기 대비 변경점 표시 | ✓ |
| 변경점만 먼저 표시 | 수정 항목을 먼저, 전체는 상세 보기 | |
| 새 계약만 표시 | 이전 미리보기와 비교하지 않음 | |

**User's choice:** 전체 계약과 변경점 함께 표시.

### 역할 또는 필수 도구를 쓸 수 없는 계약

| Option | Description | Selected |
|--------|-------------|----------|
| 전체 계약과 차단 사유 표시 | 검토 내용 전체와 차단 이유·해결 조치 표시 | ✓ |
| 차단 사유만 표시 | 문제를 해결할 때까지 전체 미리보기 생략 | |
| 계약은 검토 가능하게 표시 | 승인도 허용하고 시작 단계에서만 차단 | |

**User's choice:** 전체 계약과 차단 사유 표시. 승인·시작 가능한 상태로 보이지 않게 한다.

### 비용·사용량 한도 설명

| Option | Description | Selected |
|--------|-------------|----------|
| 설정값과 계측 가능 여부 표시 | 설정·미설정 한도와 측정 가능 여부를 명시 | ✓ |
| 설정된 한도만 표시 | 사용자가 정한 제한만 간결하게 표시 | |
| 예상치도 함께 표시 | 가능한 예상 시간·사용량·비용을 추정치로 표시 | |

**User's choice:** 설정값과 계측 가능 여부 표시. 근거 없는 예상 비용은 쓰지 않는다.

**Prior decision carried forward:** Phase 14는 최종 승인을 정확한 다이제스트를 지정하는 CLI 단계로 정했고 승인과 실행 시작을 분리했다.

## 채팅 종료 후 제어

### 실행을 다시 찾기 위한 정보

| Option | Description | Selected |
|--------|-------------|----------|
| 식별자와 다음 명령을 함께 표시 | 계약·실행 ID, 계약 경로, 복사 가능한 제어 명령 | ✓ |
| 식별자만 표시 | 명령 형식은 CLI 도움말에서 확인 | |
| 최근 작업을 자동 선택 | 식별자가 없으면 최근 실행을 제어 | |

**User's choice:** 식별자와 다음 명령을 함께 표시.

### 실행 이력이 여럿일 때 기본 조회

| Option | Description | Selected |
|--------|-------------|----------|
| 최신 실행을 명시해 표시 | 최신 실행의 ID와 시각을 눈에 띄게 표시 | ✓ |
| 실행을 먼저 선택하게 하기 | 이력이 둘 이상이면 실행 ID 요구 | |
| 모든 실행을 요약하기 | 실행별 상태 목록 후 상세 조회 안내 | |

**User's choice:** 최신 실행을 명시해 표시.

### `stop` 요청 후 종료 전 상태

| Option | Description | Selected |
|--------|-------------|----------|
| 요청과 완료를 구분 | 중지 접수와 실제 `stopped`를 별도 표시 | ✓ |
| 종료 확인까지 기다리기 | 최종 상태만 보여줄 때까지 명령 대기 | |
| 요청 즉시 `stopped` 표시 | 실제 종료 확인 전에도 완료로 표시 | |

**User's choice:** 요청과 완료를 구분.

### 중지 완료 후 재개 안내

| Option | Description | Selected |
|--------|-------------|----------|
| 재개 가능 여부와 정확한 명령 표시 | 재개 가능성, 선행 확인, 복사할 명령 안내 | ✓ |
| 상태만 표시 | 나중에 `status` 또는 `resume`에서 확인 | |
| 다음 채팅에서 안내 | 하네스 스킬을 다시 사용할 때 제안 | |

**User's choice:** 재개 가능 여부와 정확한 명령 표시.

## 상태와 진단 출력

### `task status` 첫 화면

| Option | Description | Selected |
|--------|-------------|----------|
| 현재 판정과 다음 조치부터 | 상태·이유·사용자 조치를 먼저 표시 | ✓ |
| 진행 상황부터 | 완료·남은 단계를 먼저 표시 | |
| 실행 정보부터 | 에이전트·도구·사용량을 먼저 표시 | |

**User's choice:** 현재 판정과 다음 조치부터.

### `task report` 기준별 상세 순서

| Option | Description | Selected |
|--------|-------------|----------|
| 미충족·확인 불가 기준부터 | 조치가 필요한 기준을 앞에 두고 모든 기준을 포함 | ✓ |
| 계약의 원래 순서대로 | 승인된 기준 순서를 유지 | |
| 실행 시간순으로 | 기준을 검토한 시각에 따라 표시 | |

**User's choice:** 미충족·확인 불가 기준부터.

### `task doctor` 진단 대상

| Option | Description | Selected |
|--------|-------------|----------|
| 전체 진단과 작업별 진단 모두 제공 | ID 없이는 환경, ID를 주면 특정 작업 진단 | ✓ |
| 작업 ID 필수 | 특정 작업만 진단 | |
| 최근 작업 자동 진단 | ID 없으면 최신 실행 선택 | |

**User's choice:** 전체 진단과 작업별 진단 모두 제공.

### `--json` 실패·차단 결과

| Option | Description | Selected |
|--------|-------------|----------|
| 구조화된 오류와 다음 조치 반환 | 상태·사유 코드·식별자·다음 조치를 JSON으로 반환 | ✓ |
| 성공 결과만 JSON으로 | 실패 이유는 일반 오류 문장으로 반환 | |
| 상태 코드만 JSON으로 | 자세한 이유는 사람용 출력에서만 제공 | |

**User's choice:** 구조화된 오류와 다음 조치 반환.
