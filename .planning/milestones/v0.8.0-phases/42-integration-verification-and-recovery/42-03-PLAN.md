## Trust Boundaries

| Boundary | Description |
|---|---|
| per-harness evidence → batch decision | 여러 독립 결과가 shared installation/multi-tool activation decision으로 합쳐진다. |
| batch decision → native installers | reviewed all-pass decision이 여러 external mutations를 시작한다. |
| postcheck proofs → accepted chain | 실제 invocation proof가 durable accepted identity를 바꾼다. |
