   - Call `canonicalizeWithMissingTail(resolve(targetPath))`.

   - Return canonical absolute path normalized with no trailing separator (unless root directory).

2. Implement `comparablePath(p: string): string`:
   - Check host case sensitivity (`process.platform === "win32" || process.platform === "darwin"`).
   - On case-insensitive hosts, normalize via `.toLowerCase()`. On Linux, preserve casing.

3. Implement `computeTreeId(canonicalPath: string): string`:
   - Compute SHA-256 of `comparablePath(canonicalPath)`.
   - Return the first 16 hexadecimal characters (`[0-9a-f]{16}`).

4. Implement `withinTreeRoot(root: string, candidate: string): boolean`:
   - Compare whole path segments using `comparablePath` and path separator `sep`.
   - Reject substring collisions (e.g. `/path/to/project-fork` is NOT within `/path/to/project`).

5. Implement `resolveEffectivePolicy(targetPath: string, registeredTrees: readonly TreeRegistryEntry[]): Promise<EffectiveTreePolicy>`:
   - Resolve `canonical` path via `canonicalizeTreePath(targetPath)`.
   - Filter `registeredTrees` to find all entries where `withinTreeRoot(tree.path, canonical)` is true.
   - If matching list is empty, return:
     ```typescript
     {
       entry: null,
       inherited: false,
       depth: 0,
       effectiveMode: "unclassified",
       targetPath,
       canonicalPath: canonical,
     }
     ```
   - Sort matching entries descending by path length (`comparablePath(b.path).length - comparablePath(a.path).length`).
   - Deepest ancestor (longest prefix) is `nearest = matching[0]`.
   - Check exact match: `comparablePath(nearest.path) === comparablePath(canonical)`.
   - Return:
     ```typescript
     {
       entry: nearest,
       inherited: !isExact,
       depth: matching.length,
       effectiveMode: nearest.mode,
       targetPath,
       canonicalPath: canonical,
     }
     ```
  </action>
