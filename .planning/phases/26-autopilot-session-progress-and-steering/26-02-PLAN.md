<interface_contract>
readTaskSessionPacket takes the complete TaskSessionBinding plus stateRoot, optional afterSequence and explicit small limit; returns schemaVersion, binding, observedAt, lastMeaningfulActivityAt, sourceCursor, truncated/gap facts, actual workflow/current evidence, bounded recent events, proposal dispositions, process/delivery/native capability facts and inert allowlisted evidence summaries. Cap serialized output at 64KiB, at most 50 events and 20 evidence summaries; each summary <=2KiB, reason <=1KiB, proposal <=8KiB. Return explicit unknown/truncation, not invented continuity. Do not accept arbitrary evidence/source paths or report-wide usage from unrelated runs.

TaskSteeringProposal has schemaVersion, full binding, requestId, submittedAt, text and optional bounded allowlisted evidence IDs. TaskSteeringAck is an append-only fact with proposal digest, binding, sequence, state received|delivered|assessed|deferred|rejected|applied, responsible actor/dispatch identity, recorded reason and evidence refs. This is a delivery/disposition ledger, not another task lifecycle. A record may be delivered then deferred or rejected; assessed does not imply accepted. applied requires a matching responsible GSD boundary/action receipt proving what changed under the same approved authority. Repeated requestId+content is idempotent; same ID+different content is refused. Records are private bounded files beneath the existing external digest/run/session root and use existing safe atomic helpers.

consumeTaskSteeringAtBoundary takes binding, existing controller ownership proof, exact current contract and a boundary identity tied to the next normal dispatch. It revalidates approval/revision, serializes consume/ack and returns bounded proposal text plus disposition recording hooks. It never starts a process, calls a model, rewrites PLAN.md or approves a contract. Semantic assessment occurs in the already scheduled responsible controller/GSD step; deterministic checks can refuse known authority changes, and unknown semantic authority is deferred/revision-required. Never record applied based on a model claim alone without corresponding bound effect/action evidence. If there is no later normal controller boundary, retain deferred/no-safe-boundary instead of creating one.
</interface_contract>
