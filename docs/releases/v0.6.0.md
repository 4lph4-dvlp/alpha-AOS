# alpha-AOS 0.6.0

This release adds shared strict/flexible project behavior, six task execution styles, initialization and recovery handoffs, and packaged cross-harness evidence.

Release fixes make bootstrap tests independent of the developer's installed tools, enforce the requested phase when reconciling native artifacts (including decimal phases), and serialize cancellation marker publication and cleanup. CI verifies one authoritative Linux-built package on Linux, macOS and Windows. GitHub publication reuses that exact package, verifies its checksum and all four CI jobs, and verifies uploaded bytes before making the release public.

Download `alpha-aos-0.6.0.tgz` and its checksum. Node.js 24 or later, npm 10 or later and Git are required. Install the downloaded tarball with `npm install --global ./alpha-aos-0.6.0.tgz`. This GitHub release does not publish a package to the npm registry or change any existing global installation.

The attached `release-evidence.json` identifies the tested source commit and CI run. `release-assets.sha256` verifies the package, its companion checksum and the evidence file. Historical planning ledgers remain archival; their pending statuses do not represent the current CI run. Seven archived native receipts, nineteen fixture cells, seven unsupported cells, twenty-one unverified cells and one blocked cell remain distinguished in the packaged support evidence. CI success does not turn fixture or archived evidence into fresh native model execution. Hermes remains worker-only; Claude's isolated authenticated canary remains held. No new paid native turns are claimed.
