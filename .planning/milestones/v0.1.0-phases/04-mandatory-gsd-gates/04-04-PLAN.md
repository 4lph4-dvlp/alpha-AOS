In `src/core/worker-authority.ts`:
- Implement `snapshotPlanningTree(planningRoot: string): Promise<{ digest: PlanningTreeDigest; files: Map<string, Uint8Array> }>`:
  - Traverses `planningRoot` recursively, computing `beforeDigest = await hashPlanningTree(planningRoot)`.
  - Concurrently snapshots all file byte contents into an in-memory `Map<string, Uint8Array>` keyed by relative POSIX paths.
- Implement `restorePlanningTreeSnapshot(planningRoot: string, snapshot: { digest: PlanningTreeDigest; files: Map<string, Uint8Array> }, diff: PlanningTreeDifference): Promise<void>`:
  - For files in `diff.modified`: restores original bytes from `snapshot.files`.
  - For files in `diff.removed`: restores deleted files from `snapshot.files`.
  - For files in `diff.added`: unlinks/removes unauthorized newly created files.
- Implement `witnessWorkerDelegation<T>(params: { projectRoot: string; harnessId: HarnessId; role: GsdRole; action: () => Promise<T> }): Promise<{ result: T; witness: WorkerDelegationWitness }>`:
  1. If `params.role === "controller"`, execute `params.action()` directly.
  2. For `role === "worker"`:
     - Resolve `planningRoot = join(params.projectRoot, ".planning")`.
     - Pre-witness: take full byte snapshot: `preSnapshot = await snapshotPlanningTree(planningRoot)`.
     - Execute worker action:
       ```typescript
       let result: T;
       try {
         result = await params.action();
       } catch (error) {
         // Even on failure, witness whether .planning was touched
         const errDigest = await hashPlanningTree(planningRoot);
         const errDiff = comparePlanningTrees(preSnapshot.digest, errDigest);
         if (!errDiff.equal) {
           await restorePlanningTreeSnapshot(planningRoot, preSnapshot, errDiff);
         }
         throw error;
       }
       ```
     - Post-witness: `afterDigest = await hashPlanningTree(planningRoot)`.
     - Compare: `diff = comparePlanningTrees(preSnapshot.digest, afterDigest)`.
     - If `!diff.equal`:
       - Unauthorized mutation detected!
       - Automatically restore modified/deleted files and delete newly created files using `restorePlanningTreeSnapshot(planningRoot, preSnapshot, diff)`.
       - Throw `WorkerAuthorityError("planning-mutation-detected", params.harnessId, "Unauthorized .planning/ mutation by worker harness " + params.harnessId + ". Rolled back.", [...diff.modified, ...diff.added, ...diff.removed])`.
     - Return `{ result, witness: { harnessId: params.harnessId, role: "worker", planningRoot, immutable: true, beforeDigest: preSnapshot.digest.digest, afterDigest: afterDigest.digest, modifiedPaths: [] } }`.
  </action>
  <acceptance_criteria>
    - `witnessWorkerDelegation` captures recursive tree hash before and after worker execution.
    - Any modification to `.planning/` by a worker triggers `WorkerAuthorityError` and rolls back `.planning/` state (D-11).
    - Clean worker runs succeed with an auditable `WorkerDelegationWitness`.
  </acceptance_criteria>
