<objective>
Build the host-scoped record that everything else in this phase writes to and reads from.

Purpose: CAPA-07 — a user must be able to distinguish a capability that is selected, deployed, natively
discovered, actually invoked, blocked, stale, unsupported or unverified, instead of one misleading
installed state. CONTEXT.md D-11 models that as orthogonal axes, never one eight-value enum. CONTEXT.md
D-03 puts the evidence under the user state root, because "this harness on this machine discovered this
skill" is a host fact that becomes false on a colleague's machine if committed. CONTEXT.md D-04 binds a
proof to exact inputs and demotes it when they move.

Output: a closed schema, a reader that fails closed, a writer that goes through the single write path,
and the paired-evidence rule that stops an unpaired positive reading as a pass.
</objective>
