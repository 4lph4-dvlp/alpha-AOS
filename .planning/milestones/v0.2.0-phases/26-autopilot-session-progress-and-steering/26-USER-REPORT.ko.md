# alpha-AOS 개선 보고 — 2026-11-01

## 해결해야 했던 문제

Oh-My-Circuit의 승인된 전용 GSD 실행에서 단계 횟수 제한이 실제 모델 호출·
토큰·하위 세션 예산을 통제하지 못했고, 관리 작업과 반복 검토에도 큰 문맥을
계속 사용했습니다. 컨트롤러가 한도로 종료돼도 작업이 running으로 남았으며,
사용자는 수동으로 질문해야 진행 상황을 알 수 있었습니다.

제공된 네 구간의 773.68크레딧은 Standard 단가 환산값입니다. 실제 청구액이나
이번 수정의 실제 차감액으로 표현할 근거는 없습니다.

## 조사로 확인한 사실과 계획

기존 telemetry, 자원 한도 평가, supervisor checkpoint, durable job을
폐기할 문제가 아니라 실제 실행 경로에 연결할 문제였습니다. generic 경로와
등록된 전용 경로를 구분하고, 공통 dispatch 경계에 계측·예산·종료 관측을
연결했습니다. Supervisor 토큰 누적은 조사·수정 대상이지 과거 실행의 직접
원인으로 단정하지 않았습니다.

다섯 에이전트 모두에서 아무 모델 호출 없이 기존 대화에 즉시 알림을 넣는
공통 기능은 검증되지 않았습니다. 사용자 승인에 따라 공통 진행 패널과
시작한 대화의 질의·제어를 결합했습니다. 네이티브 대화 알림은 검증되지 않은
채로 활성화하지 않았습니다.

## 수정 전과 후

| 항목 | 수정 전 문제 | 구현한 동작 |
|---|---|---|
| 예산 | 큰 단계 수와 실제 사용량 혼동 | 단계·관측 호출·토큰·추정 비용 구분, 공통 실행 경계의 예산 검사 |
| 사용량 | 하위 세션·재개 누적의 연결 누락 위험 | 중복 방지와 누적 관측, 측정 불가는 null/불가로 유지 |
| 종료 | 부모가 죽어도 running 잔존 | 런타임의 지속 실행 기록과 실제 종료 확인, 불명 상태 구분 |
| 관리 | 대기·회계·상태 확인에 모델 사용 | 일반 런타임의 타이머·기록·중복 제거·관측 |
| 검토 | 동일 근거 전체 재검토 반복 | 검토 근거 재사용과 변경 관련 검토, 최종 독립 검토 유지 |
| 진행 | 수동 질의에 의존 | 선택형 공통 실시간 패널, 정확한 실행에 다시 연결 |
| 질의 | 문서·대화 전체를 다시 조사 | 한 실행의 제한된 근거 패킷 조회 |
| 의견 | 접수와 실제 반영 구분 부족 | 접수·전달·검토·보류·거절·반영 사실을 별도 기록 |
| 승인 | 변경 요청이 권한 변경으로 이어질 위험 | 기존 컨트롤러의 안전한 경계에서 검토, 권한 확대는 새 계약 승인 |

구형 임의 PowerShell 래퍼 전체를 그대로 안전하게 지원한다고 주장하지
않습니다. 등록된 typed 실행 경로에 통제를 연결했으며, 기존 구형 전용
실행은 지원 경로로의 이행이 필요합니다. 원 프로젝트는 자동 재개하지 않았습니다.

## 현재 검증 상태

비용·종료·복구 개선인 Phase 25는 전체 1,857개 중 1,846개 통과,
11개 건너뜀, 실패 0으로 검증을 마쳤습니다. 추가 진행 보고 기능인 Phase 26은
세 구현 계획을 완료했습니다. 독립 검토에서 발견한 다섯 결함을 수정하고
해당 변경의 독립 확인을 받았으며, 실제 Chrome 상호작용 확인도 통과했습니다.

Phase 26의 최종 전체 테스트는 **1,938개 중 1,926개 통과, 12개 건너뜀,
실패 0개**로 완료했습니다. 처음 전체 실행에서 발견한 저장소 초기화 충돌을
수정하고 독립 확인을 받은 뒤 다시 실행한 결과입니다. 함께 발생했던
체크포인트 실패는 최초 원인을 확정하지 못했지만, 승인 조건을 완화하지
않은 최종 전체 실행에서는 통과했습니다. 두 실행의 기록을 모두 보존했습니다.

최종 GSD 목표 검증은 핵심 조건 **14/14**와 **SESSION-01..06**을 통과했습니다.
검증 보고서의 소스 지문을 확인한 뒤 Phase 26과 요구사항을 완료 처리했습니다.
전역 설치·배포와 원 프로젝트 재개는 하지 않았습니다.

이번 구현에서도 초기 설계 재검토와 일부 검증 반복으로 시간이 길어졌습니다.
실제 절감액은 측정하지 않았으며, 일부 TDD 절차 누락도 기록에 남겼습니다.
이번 요청의 남은 두 작업인 전체 테스트 확인과 최종 수락 검증은 완료됐습니다.
다섯 호스트의 공통 패널을 제공하며, 네이티브 대화 알림은 검증되지 않아
활성화하지 않았습니다. 브라우저 자체 200% 확대는 미검증으로 남겼고,
200% CSS 확대와 작은 화면의 재배치는 실제 브라우저에서 확인했습니다.

조사용 임시 폴더는 새 승인을 반영해 정확한 경로와 링크 부재를 확인했지만,
삭제 명령이 자동 승인 검토에서 다시 `blocked by policy`로 거부됐습니다.
폴더는 남아 있으며 다른 방식으로 우회하지 않았습니다.
