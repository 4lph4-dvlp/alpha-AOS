## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GSD Interactive Question $\rightarrow$ Autonomous Auto-Answer | External or generated prompts evaluated against authorized task contract boundaries |
| CLI User Input $\rightarrow$ Paused Task State | User answer provided via CLI task answer reconciled into durable task checkpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-09 | Elevation of Privilege | Boundary escalation via prompt auto-answer | critical | mitigate | evaluateGsdPromptQuestion strictly verifies allowedRoots, allowedEffects, and resource budget before allowing auto-answer, forcing needs-input pause on violations (D-02). |
| T-17-10 | Repudiation | Unaccounted automated decision | medium | mitigate | All auto-answered prompts are logged into execution journal under category gsd-default with choice, rationale, and criterion bindings (D-01). |
| T-17-11 | Tampering | Answer injection into inactive run | medium | mitigate | CLI task answer verifies checkpoint status is strictly needs-input before recording answer and transitioning state (D-03). |
| T-17-12 | Denial of Service | Unhandled ambiguous prompt deadlock | medium | mitigate | Any prompt without a recommended default immediately transitions to needs-input with actionable CLI commands displayed (D-02, D-03). |
</threat_model>
