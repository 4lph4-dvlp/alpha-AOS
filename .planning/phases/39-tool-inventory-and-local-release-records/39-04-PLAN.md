Research Open Question 2 is RESOLVED before execution. Task 39-04-01 must implement `39-RESEARCH.md` section `기존 증거와 인계 판정 계약` and its five-link decision: trusted official publisher/source → exact version/artifact → artifact-bound trusted expected digest plus actual verification result → current installed bytes or explicitly identified transformation outputs match → prior ownership and user-modification evidence. All links must agree on subject and checked scope. Read `src/core/ecc-fixture.ts`'s tarball integrity and source/target hash return, `src/core/mcp-fixture.ts`'s npm pack metadata comparison/archive presence, the existing Cua file comparison and the research matrix before the action. These routines are evidence-shape references; do not execute package fixtures during observation or handoff evaluation.

Stable lock supplies selected identity/expected hashes only. An applied file journal supplies file-change/operation linkage only. ECC's returned source/target hashes contribute only if trustworthily retained and linked to the exact artifact, transformation rule/revision and current targets. MCP pack metadata/archive presence alone does not prove current installation bytes. Cua pin booleans/strings and installed-file match alone do not authenticate the artifact's official origin. For transformed files, require the retained artifact/source-hash → identified transformation revision/parameters → expected target-hash → current target match chain; missing transformation evidence is precise insufficiency, not a future implementation choice. Sufficient existing chains permit ready without downloading/reinstalling. Missing/conflicting/unreadable links return the specific missing evidence and next action; partial-file proof covers only those files, and unperformed integration remains unverified.
