## Reviewed transfer and host-read boundary

Prepare preview returns a planDigest over root identity, destination, content and native inputs. Apply requires that exact planDigest in the input packet and rechecks drift under the held writer session. Claim/link/ack/cancel similarly bind their previewed expected content/evidence digest. A read-only preview is not an approval request by itself; existing user effect authority governs application. A stale preview cannot overwrite a different request.

The private host API is a bounded local data API, not a new authentication system. The invoking skill can read the exact reviewed regular record using its authorized file-read surface (max32KiB, exact root/pending/content digest), or call readTaskBootstrapHandoff with those same proofs; no private facts are printed by the public CLI. No unbounded --include-private flag.
