      - Killing supervisor before effect write recovers accurately and applies effect.
      - Killing supervisor after effect file write but before checkpoint reconciles via file sha256 to applied and skips re-execution.

| STRIDE Category | Threat Description | Mitigation Strategy |
|---|---|---|
| Tampering | Resuming a task after external modifications corrupts repository or violates contract | Pre-resume verification of GSD STATE and Git HEAD against checkpoint (D-04). |
| Repudiation | Ambiguity over why a supervisor run stopped or what resources were spent | Standard stop codes with full usage breakdown and unmetered field disclosures (D-15). |
| Denial of Service | Unchecked crash recovery loops attempt the same failing action infinitely | Effect reconciliation detects already-applied effects; no-progress detector escalates to blocked (D-07, D-10). |
| Information Disclosure | Sensitive credentials in environment or memory dumped during supervisor crash recovery | Process streams redacted at write time; only sanitized summaries in checkpoints (D-03). |
</threat_model>
