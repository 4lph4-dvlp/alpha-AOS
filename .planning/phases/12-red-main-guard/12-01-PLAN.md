<objective>
Deliver the core guard logic and unit test suites for Phase 12 as a robust tracer slice.

Implement two standalone Node.js ES modules under `scripts/`:
1. `scripts/red-main-guard.mjs`: Manages the tracking issue lifecycle for `main` CI failures (opens on failure, refreshes on persistent failure without duplication, auto-closes on green, parses 3-OS matrix legs, preflights labels).
2. `scripts/check-main-baseline.mjs`: Checks completed `main` CI runs for candidate promotion gating (reports eligible on green, blocked on red, fails closed on null runs or API errors, safely toggles `promotion-blocked` label, and renders idempotent status banners).

Both modules support dependency injection of a `CommandExecutor` function so unit test suites under `test/` (`test/red-main-guard.test.ts` and `test/check-main-baseline.test.ts`) can run 100% in-memory with zero subprocess or network dependencies.
</objective>
