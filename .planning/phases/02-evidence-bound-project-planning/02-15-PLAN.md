<objective>
Close the two remaining review findings that change the SHAPE of `ProjectCapabilityPlan`, and prove that
after both changes `project approve` still writes an artifact `project status` accepts. Its sibling 02-16
closes the two findings that change no shape — the root-keyed catalog caches and the drift check's home —
and runs in a later wave for that reason.

The heavier of the two is WR-01, and it contradicts the property this phase was built to have.
`discoverPersonalSkillNames` reads the reviewer's home-directory skill roots on the PREVIEW path; a hit
appends a `SKILL_SHADOWED` approval; `approvals` is folded into `digestablePlan`. Two people reviewing
the identical commit of the identical repository therefore compute different `planDigest` values, and a
digest reviewed on a laptop cannot be approved on CI. The verifier ran on one host and could not see it;
the reviewer found it by reading the digest's inputs.

The other is WR-04 with WR-14 beside it: a safe inverse whose guard hash is invented for bytes that were
never read, and a paste-ready command quoted only when the path contains whitespace.

Both findings widen a field that `approvalArtifactBytes` serializes wholesale into `.alpha-aos/plan.json`
— WR-01 adds `hostNotes: string[]`, WR-04 admits a null `guard.expectedHash` — and plan 02-14 closed that
artifact's world with `additionalProperties: false` one wave earlier. 02-14 is therefore told to type
those two shapes up front, and this plan owns the schema file to tighten `hostNotes` into `required` once
it exists and, more importantly, to ASSERT the round trip: approve a real plan, then read it back with
`status`, and require `artifactState: current`. Without that assertion the contract between the two plans
is a hope.

Purpose: DETC-04 promises stable text and JSON plans and DETC-05 promises a refusal that is a next step
rather than a dead end. A digest that varies by host breaks the first; a command that does not parse
breaks the second; an approval its own reader rejects breaks both at once.

Output: a host-independent plan digest that still reports the host-specific fact, an honest safe inverse,
a paste-safe command, and a proven approve-then-read round trip across both shape changes.
</objective>
